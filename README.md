# Padaria Pani Di Grano 🍞

Aplicativo completo de delivery, encomendas e gestão para a padaria Pani Di Grano.

## 📱 Funcionalidades principais
- Delivery com rastreamento GPS em tempo real
- Encomendas grandes com pagamento por PIX/cartão
- Notificações por SMS, e-mail e push
- Painel Admin com vendas diárias, semanais e mensais
- Cadastro de clientes e histórico de pedidos
- Gráficos e métricas de desempenho

## 📦 Tecnologias
- React Native (Mobile)
- Node.js + Express (Backend)
- PostgreSQL ou MongoDB (Banco de dados)
- Axios, TailwindCSS, Styled Components
